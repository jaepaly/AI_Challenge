### E2. 자발적 매도가 반대매매를 중단시키는가 → **해소된다. 단 회사별로 경로가 다르다** ✅

| 회사 | 원문 | 해소 경로 |
|---|---|---|
| **유진** | *"담보부족발생일(D), (D+1)일 **일반매매를 통해 일부상환 방식으로 해소가능**"* / 미수: *"당일 장개시 전까지 미수금 전액을 입금 시 자동으로 반대매매 거부/취소"*, *"8:30분 이전 고객 요청시 관리점 통해 종목교체 가능"* | D·D+1 일반매매 / 장개시 전 입금 자동취소 / 8:30 전 종목교체 |
| **키움** | *"익일에 반대매매 처리되는 경우 **고객이 매매 재개일 당일에 직접 매도하여 미수변제 가능**"* | 당일 직접 매도 |
| 한국투자 | *"매매에 의하여 상환을 하고자 할 때에는 상환하고자 하는 날의 **전전일**(휴장일 제외)까지 회사에 신청하여 동 매매의 **결제일에 상환**"* | 전전일 사전 신청 + 결제일 상환 |
| 삼성·신한·메리츠 | 동일 취지 문구 (전전일 신청 → 결제일 상환) | 동일 |

**결론**: "오늘 팔면 내일 반대매매가 멈추는가"의 답은 **회사마다 다르다.**
- 유진·키움 = **당일/직전일 직접 매도로 해소 가능** (명시적)
- 한투·삼성·신한·메리츠 = **매매에 의한 상환은 전전일 신청 + 결제일 상환**이라는 별도 절차

→ 이것은 기획서의 "회사마다 다르다"를 **처분 수량(h)뿐 아니라 대응 경로에서도** 입증하는 실증이다.
→ 기획서 4-2의 자발적 매도 행에 붙인 유보("실제 반대매매 중단 여부는 회사별 확인 필요")를
   **"회사별 해소 경로 상이 — 유진/키움은 직접 매도 가능, 한투 등은 전전일 신청 필요"**로 격상 가능.

### E1. 담보부족 통지에 금액·기한이 포함되는가 → **부분 확인. 방법은 확정, 내용은 미확정** ⚠

| 회사 | 통지 방법 (원문) |
|---|---|
| 메리츠 | *"추가담보 납입요구는 **유선, SMS(또는 알림톡) 및 이메일**로 통보"* (고객 선택 시 유선 제외 가능) |
| 삼성 | *"추가담보 납입요구 및 반대매매통보는 약정시 정한 담보부족/반대매매통보 수신처(**E-mail, SMS**) 또는 통화 내용 녹취 등 요구 사실이 입증될 수 있는 방법"* |
| 신한 | *"담보부족 등의 안내 시 **등록된 휴대폰 번호로 통보**"* (수신거부·스팸등록 시 불이익 유의) |

- 확정: 통지의 공식 명칭은 **"추가담보 납입요구"**, 채널은 SMS/알림톡·이메일·유선, 회사별 상이.
- 미확정: **문자 본문에 부족금액·해소기한·예상 처분수량이 들어가는지는 약관에 없다** — 실제 수신 문자를 봐야 안다.
- 다만 현 기획서는 "문자에는 답이 없다" 계열 단정을 이미 삭제했고, 제품의 핵심 가치가 **담보부족 발생 전 사전 진단**이므로 이 항목은 더 이상 전제가 아니다. 실물 캡처가 생기면 보너스로 반영한다.
