# 약관 원문 보관소 (D 관리)

증권사 신용거래 약관·설명서 PDF를 여기에 보관한다. **B의 인제스트 입력이자 근거 좌표의 원본**이므로 아래 규칙을 지킬 것.

## 파일명 규칙

```
{증권사}_{문서종류}_{개정일 YYYYMMDD}.pdf
예) 한국투자_신용거래설명서_20260703.pdf
```

## 수집 기록 (파일 추가 시 아래 표에 한 줄 추가)

| 파일 | 심사필 번호 | 개정일 | sha256 | 원본 URL | 수집일 |
|---|---|---|---|---|---|
| (예시) | 없음 → sha256으로 대체 | 2026-07-03 | `Get-FileHash 파일명` 결과 | https://… | 2026-08-05 |

- 심사필 번호가 없는 회사(미래에셋·유진 확인됨)는 `content_sha256`이 버전 식별자다.
- sha256: PowerShell `Get-FileHash <파일> -Algorithm SHA256`
- 개정 전 버전도 삭제하지 말 것 — **개정 diff 데모의 원료**다.

## 현황 (2026-08-05 기준)

- 한국투자: 확보 (2026.2.7 / 7.3 개정 이력 있음 — 두 버전 모두 보관할 것)
- 키움: 약관 확보 / **신용거래 설명서 미확보** (D-day 미결)
- 삼성: **h(산정 기준가 할인율) 미확인**
- 지원 3사 최종 확정은 팀 회의 안건 (후보: h 편차 3종 — 한투 −15% / 메리츠 −20% / 유진 하한가)
