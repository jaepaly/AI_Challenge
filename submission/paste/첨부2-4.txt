4-1. AI 가 수행하는 역할 - 그리고 하지 않는 역할

AI 는 약관을 읽고 인용한다. 계산은 결정론 엔진만 한다.

이 경계가 이 제품의 설계 전부다. 금융 수치를 LLM 이 계산하면 왜 그 값이 나왔는지 검증할 수 없다. 그래서 역할을 이렇게 나눴다.

[표] 아래 블록만 선택 → 입력 → 표 → 표로 변환 → 탭 기준
구분	AI (claude-sonnet-5)	결정론 엔진 (TypeScript)
하는 일	약관 원문에서 유지비율 · 처분 가격 산정 기준을 찾아 인용과 좌표로 낸다	부족액 · 담보비율 · 처분 수량 · 해소 경로 · 한계선을 계산한다
안 하는 일	계산하지 않는다. 출력에 산식이 섞이면 카드를 거부한다	약관을 읽지 않는다
검증	4중 방어 (아래)	골든 테스트 · 뮤테이션 테스트


4-2. 2패스 파이프라인

Anthropic 의 citations 는 structured outputs 와 병용할 수 없다(400). 그래서 두 번 부른다.

    파싱     PDF → pypdf 텍스트 추출 / HTML → 평탄화          (14.1 ms)
    1패스    citations: {enabled: true} 로 호출                (17.9 초)
             → cited_text + 문자 좌표를 모델이 아니라 API 가 준다
             ← LLM 에게 좌표를 자가 보고시키지 않는 이유가 이것이다
    2패스    1패스의 인용을 입력으로 structured output 호출     (25.8 초)
             → ConditionCard JSON
                                                    총 43.8 초 (실측)

※ 좌표를 모델이 말하게 하지 않는다. 모델이 "이 문장은 4444자에 있다"고 보고하면 그것도 생성물이라 틀릴 수 있다. citations 는 API 가 위치를 돌려주므로 원문과 대조 가능하다.


4-3. 4중 방어 - 순서대로

    (1)  모든 수치에 근거 좌표(인용 + 문자 위치 + 문서 해시)
            좌표를 못 찾으면 → 카드 전체 거부
    (2)  JSON Schema(Draft7) 검증 + Pydantic 모델 검증
    (3)  수치 범위 검사        r 1.0 ~ 2.0 · h 0 ~ 0.35
    (4)  산식 혼입 거부        출력에 계산식이 섞이면 → 거부

그리고 인제스트 출력의 status 는 무조건 draft 다. verified 승격은 사람이 원문과 대조한 뒤에만 한다. 화면은 draft 카드를 참고 모드로 표시한다.

실측 기준 통과 기록(hankook_two_pass.json):

    status_draft                              true
    evidence_coordinates_and_quotes           true
    json_schema_and_pydantic                  true
    numeric_ranges                            true
    formula_contamination_rejected            true
    golden_h_0_15                             true

4-5. 입력 · 출력 데이터

기본 경로 (업로드 없이)
외부 API 호출 0회. 사전 계산된 조건카드 3장이 화면에 들어 있고, 판정은 브라우저에서 도는 순수 계산이다.

업로드 경로

    입력   PDF 또는 HTML 파일 1개
             .pdf / .htm / .html
             프록시 상한 4 MB   (인제스트 직접 호출은 20 MB)
             레이트리밋  클라이언트당 시간당 3건 · 전체 시간당 12건

    출력   ConditionCard JSON
             broker, ratio_rules[], disposal_price_rules[],
             각 규칙마다 evidence { quote, source_format, char_start, char_end,
                                   flattened_sha256 },
             status: "draft"   ← 무조건


4-6. 개인정보 · 민감정보 처리

개인정보를 수집하지 않는다.

[표] 아래 블록만 선택 → 입력 → 표 → 표로 변환 → 탭 기준
구분	처리 여부
계정 · 로그인	없다. 이름 · 이메일 · 연락처를 받지 않는다
실계좌 정보	읽지 않는다. 계좌는 가상값이다
쿠키 · 추적	사용하지 않는다
업로드 파일	우리 서버에 저장하지 않는다. 조건카드를 만드는 데만 쓰고 응답 후 버린다

※ 그러나 업로드 파일은 조항을 읽기 위해 Anthropic API 로 전송된다. 이것은 사실이므로 화면에도 그대로 적었다 - "올린 파일은 우리 서버에 저장하지 않습니다. 다만 조항을 읽기 위해 Anthropic API 로 전송됩니다. 대외비 문서는 올리지 마세요."

저장하지 않는다는 것은 우리 코드를 읽어 확인한 사실이고, 전송된다는 것도 사실이다. 둘 중 하나만 적으면 그 화면이 거짓말을 한다.
