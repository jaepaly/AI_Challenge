# 양식 붙여넣기 원고

`data/forms/` 의 공식 `.hwpx` 두 개에 **칸별로 그대로 붙여넣기 위한** 평문이다.
초안(`submission/attachment1-plan.md`, `attachment2-*.md`)과 **같은 내용**이고,
한글에서 깨지는 것만 바꿨다.

## 왜 따로 두는가

초안은 마크다운이다. `**굵게**` · `| 표 |` · ``` 코드블록 ``` · `~~취소선~~` 은
한글에 붙이면 **기호가 글자 그대로 나온다.** 9/7 아침에 그걸 손으로 지우게 되면
그때가 제일 틀리기 쉬운 시점이다.

## 쓰는 법

1. 한글로 `data/forms/(첨부N) ….hwpx` 를 연다
2. 절 제목 아래 칸에 커서를 두고, 같은 번호의 `.txt` 를 통째로 붙여넣는다
3. `[표]` 표시가 있는 블록은 **그 블록만 다시 선택** →
   `입력` → `표` → `표로 변환` → **탭** 기준
4. 다 채우면 `파일` → `PDF 로 저장하기`

```
첨부1-1.txt  서비스 명칭                    첨부2-1.txt  MVP 구현 범위
첨부1-2.txt  핵심내용 요약                   첨부2-2.txt  주요 기능 목록
첨부1-3.txt  문제 정의 및 제안 배경           첨부2-3.txt  사용자 이용 흐름
첨부1-4.txt  서비스 컨셉 및 차별성            첨부2-4.txt  AI 및 데이터 처리 방식
첨부1-5.txt  활용 데이터 및 생성형 AI         첨부2-5.txt  MVP 검증 방법
첨부1-6.txt  기대 효과 및 확장 가능성
첨부1-7.txt  (자유) 검증 방법과 한계
```

머리 항목은 두 양식이 같다.

```
팀명        마진가드
구성원 성명  박재현(팀장) · 김재현 · 서승기 · 이예찬
```

## ⚠ 이 파일들은 초안의 **사본**이다

내용을 여기서 고치면 초안과 갈라진다. **고칠 것이 생기면 초안을 먼저 고치고
여기로 옮긴다.** 반대 방향으로 하지 않는다 — 초안 쪽에만 검사가 걸려 있다
(`test_submission_forms.py`).

⚠ **분량 제한은 확인된 바 없다.** 양식 본문에도, 저장소 어디에도 쪽수·글자수
제한이 적혀 있지 않다. 한글에 넣어 보고 칸을 넘치면 그때 줄인다 — 지금 미리
줄이면 근거를 잃는다.

```
첨부1  12,293자      첨부2  20,394자 (§1~§4 10,761 + §5 9,633)
```
