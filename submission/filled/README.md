# 채운 양식 — 한글 작업은 **여기서** 한다

`data/forms/` 는 **주최측이 배포한 원본**이다. `data/terms/` 의 약관과 같은 취급이고,
`data/forms/README.md` 가 그렇게 적어 두었다. 한글로 열어 그 자리에서 채우면 안 된다.

## 왜 원본을 채우면 안 되나

2026-08-29 드라이런에서 실제로 그렇게 됐고, 둘을 한꺼번에 잃었다.

```
① 주최측이 양식을 고쳤는지 대조할 기준
② SubmissionFormTest 가 보는 절 구조
   §7 은 «(자유타이틀 기재)» 라 우리가 제목을 정한다 → 채우면 검사가 깨진다
```

②는 실제로 빨간불이 됐다(`7. (자유타이틀 기재)` → `7. 검증 방법과 한계`).
`FilledFormIsSubmittableTest` 가 이제 원본이 채워졌는지 본다.

## 순서

```
1  data/forms/(첨부N) ….hwpx 를 이 폴더로 복사
2  한글로 열어 절마다 submission/paste/첨부N-M.txt 를 붙여넣는다
3  [표] 표시가 있는 블록만 다시 선택 → 입력 → 표 → 표로 변환 → 탭 기준
4  🔴 [표] 로 시작하는 안내 줄을 지운다        ← 한글이 안 지워 준다
5  파일 → PDF 로 저장하기
```

⚠ **4번을 빠뜨리면 심사자가 우리 작업 지시를 읽는다.** 8/29 드라이런에서 다섯 줄이
그대로 남아 있었다. 지운 뒤 이걸로 확인한다.

```bash
python -m pytest services/ingest/tests/test_submission_forms.py -k filled -v
```

## ⚠ `.hwpx` 는 커밋하지 않는다

한글로 편집 중인 이진 파일이라 저장할 때마다 통째로 갈아엎힌다. 그래서 이 폴더의
`.hwpx` 는 추적하지 않고, 검사는 **파일이 없으면 건너뛴다**(«통과» 가 아니라
«건너뜀» 이다 — 검사가 아무것도 안 보고 있으면 그게 보여야 한다).

제출한 **PDF 는 커밋한다.** 그건 더 안 바뀌고, *"우리가 낸 것이 이것"* 의 기록이다.
