# 랜딩 와이어프레임 (D · Phase 1)

"주가를 이 선까지 끌어내려 보세요" — 1차 심사위원이 URL을 열고 **30초 안에 마우스로 숫자가 바뀌는 경험**의 프로토타입.

## 실행

```bash
cd apps/landing-proto
npm run build              # esbuild 번들 (dist/bundle.js)
python -m http.server 8802 # 또는 아무 정적 서버
# → http://localhost:8802
```

## 원칙 (코드 리뷰 포인트)

- **수치는 전부 `packages/engine` import** — 이 앱에 산식이 없다. 임계가(8,400원)조차 `engine.shortfall`을 오라클로 이분 탐색해서 구한다.
- **표시 순서 규약**: 안전 여유 먼저, 임계점 나중 (기획서 4-2).
- **담보비율 표시는 내림**, 엔진 재현값(사사오입) 병기 — A·D 합의 안건 `#표시규약`. 합의되면 한 줄 수정.
- draft 카드 → "참고 모드" 배너 강제. 회사 간 우열 형용사 없음(수량 숫자만).
- 7월 연쇄는 **1차 관통일 탐지까지만** — 집행(원장 갱신) 반영 경로 시뮬은 A의 `replay` 완성 후 교체.
